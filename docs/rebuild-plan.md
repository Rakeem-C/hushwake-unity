# Unity rebuild acceptance

1. Install the pinned Unity Editor with Web Build Support and activate the owner's eligible license.
2. Import and validate the authored content catalog without changing the original game.
3. Implement a Unity world with region traversal, character movement, camera, interactable NPCs, combat, Wake/Hush changes, and progression.
4. Implement the dungeon machinery, bosses, abilities, inventory, journal, and final choice.
5. Implement versioned local saves with visible error handling and migration boundaries.
6. Build with Unity's Web target, then play through ordinary keyboard and mouse input in a browser. Capture errors, frame rate, and save/reload evidence.
7. Publish the verified Web build on Vercel and add the actual public link to README.md.

The public repository is a new project. Keep the original Sites and Three.js publishing work independent. Never claim a full campaign or a Unity Web release based on exported content, compilation alone, or a placeholder page.
